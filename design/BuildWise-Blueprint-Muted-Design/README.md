The original Blueprint design is retained: midnight navy navigation, a cool light workspace, white cards and the same layouts. The bright orange accent is replaced with a dimmer terracotta (#AA6248), including buttons, navigation markers, icons, logo and blueprint illustration.

The screens folder includes all 20 main screen designs and selected mobile layouts. The overview image presents the main pages together. Editable muted-logo SVG files are included.

The prototype stores edits locally in the browser. Backend authentication, AI and email are not connected. No demo data labels are displayed.
