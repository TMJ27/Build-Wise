# BuildWise Design 02 Comfort

Preview: http://localhost:5180/design-two#/dashboard
Screen library: http://localhost:5180/design-two#/brand
Original light design: http://localhost:5180/#/dashboard

This design uses charcoal backgrounds, off-white text, muted sand accents and readable supporting text across all 20 main screens. Native form controls use a dark colour scheme. Printed quotations retain a light paper layout.

The design is intended as a lower-brightness visual alternative. The first design remains available for comparison. No demo data labels appear in either interface.

Screen exports are in the screens folder. Editable Comfort logo assets are included in the design package.

The existing prototype interactions remain available. Authentication, AI, server storage and email are not connected. Edits remain local to the browser.

Validation: .NET build with zero warnings and errors; all main routes render; request search, scope approval, quotation approval and retained revisions pass; mobile overflow checks pass.
